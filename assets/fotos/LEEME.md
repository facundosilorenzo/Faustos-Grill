# Fotos del restaurante

Coloca aquí las fotos con **estos nombres exactos** (JPG, idealmente 1600 px de ancho y menos de 400 KB cada una):

| Archivo | Dónde aparece |
|---|---|
| `hero.jpg` | Fondo de la portada (horizontal, oscura funciona mejor) |
| `ojo-de-bife.jpg` | Galería, foto grande |
| `parrilla.jpg` | Galería, vertical |
| `provoleta.jpg` | Galería |
| `empanadas.jpg` | Galería |
| `parrillada.jpg` | Galería, horizontal |
| `salon.jpg` | Galería |
| `postre.jpg` | Galería |

Mientras falte una foto, la web muestra un recuadro con el nombre del plato en su lugar,
así que nunca se ve una imagen rota. Para cambiar platos o textos de la galería, edita la
sección `Fotos` de `index.html`.
